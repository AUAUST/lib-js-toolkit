# Project map

Generated by `engrenage sync agents` from the project structure. Do not edit.

## Notation

Trees: `name*` public domain, `{…}` sub-domains, `#alias/…` import alias, `[isolated]` peers never import each other.

| Relation         | A domain may import                                                                           |
| ---------------- | --------------------------------------------------------------------------------------------- |
| `own-roles`      | its own roles and files, excluding its index and entry                                        |
| `global-roles`   | the global roles of the environment root                                                      |
| `ancestor-roles` | the roles of its ancestor domains, as a sub-domain                                            |
| `sub-domain`     | the target's `index.ts` and public roles, through its nearest sub-domain's surface            |
| `lower-layer`    | the target's `index.ts` and public roles, through a domain in a lower layer                   |
| `peer`           | the target's `index.ts` and public roles, through a peer domain (same layer, unless isolated) |
| `root-entry`     | any public surface, from the environment root file                                            |

## Environments

The matrix states environment grants; domain and role boundaries still apply. No importer but its environment's root `executable.ts` may import a root index or entry file of `src`, `scripts`, `tooling`. `scripts`, `tooling` import `src` only through a domain's `index.ts`, `entry.ts` and public roles.

| Category           | Meaning                           |
| ------------------ | --------------------------------- |
| `public-entries`   | the package name and its subpaths |
| `internal-aliases` | `#…` aliases into `src`           |
| `tests`            | the tests environment's files     |
| `scripts`          | the scripts environment's files   |
| `tooling`          | the tooling environment's files   |
| `data`             | the data environment's files      |
| `dist-artefacts`   | the build output                  |

| from / to | public-entries | internal-aliases | tests | scripts | tooling | data  | dist-artefacts | map                                    |

| `src`     | yes            | yes              | never | never   | never   | never | yes            | `.claude/rules/project-map/src.md`     |

## Roles

Effect levels, purest first: `pure` < `confined` < `observing` < `effectful`. A role with a level imports at runtime only roles of its level or a purer one. Global roles import only each other. Other domains import a `collected` role's modules inside sub-domains too, past their parent domains' surfaces.

- `pure`: Compute from arguments only, without observable changes.
- `confined`: Mutate caller-owned values or maintain a private memo cache.
- `observing`: Read the context or write diagnostics without changing state later operations read.
- `effectful`: Change state later operations can read, including staged writes and spawned processes.

| Role         | Purpose                                                                                            | Files           | Level     | Imports   | Environments     |
| ------------ | -------------------------------------------------------------------------------------------------- | --------------- | --------- | --------- | ---------------- |
| `utils`      | Confined functions, one per module.                                                                |                 | confined  |           | `src`            |
| `constants`  | Deeply read-only constants of the domain.                                                          | `constants.ts`  | pure      | public    | `src`            |
| `entrypoint` | The package entry of a public domain, re-exporting the public subset of its surface.               | `entry.ts`      |           |           | `src`            |
| `errors`     | Error classes, importable module by module.                                                        |                 | pure      | public    | `src`            |
| `index`      | The domain's public surface.                                                                       | `index.ts`      |           |           | `src`, `scripts` |
| `types`      | Types only, one per module.                                                                        |                 |           | type-only | `src`            |
| `testutils`  | Reusable test utilities.                                                                           |                 | effectful |           | `tests`          |
| `fixtures`   | Static test inputs.                                                                                |                 | pure      |           | `tests`          |
| `executable` | A program's executable: it loads the program's root group and runs it.                             | `executable.ts` |           |           | `scripts`        |
| `commands`   | One command's description, arguments and options, and the glue to its action.                      | `*.ts`          |           |           | `scripts`        |
| `actions`    | The behavior of one command, without its name, aliases or argument structure, loaded when it runs. |                 | effectful |           | `scripts`        |
