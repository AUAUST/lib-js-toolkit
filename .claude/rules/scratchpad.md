# Scratchpad

Process `.ai/scratchpad.md` only on request, including “handle the scratchpad”. Never delete it or implement its suggested work.

1. Read the notes and `.ai/backlog/index.md`. Ignore the sentence following `<!-- scratchpad-placeholder -->`.
2. Inspect relevant project context and categories. List proposed entries and existing IDs covering or overlapping each note.
3. Clarify conflicts or missing context before writing affected entries. Retain unanswered notes; proceed with clear items.
4. Create or update entries using the index's category and numbering rules; reuse existing coverage.
5. Remove only recorded or already-covered notes. Report their backlog IDs.
6. When empty, retain the heading and placeholder marker. Add a fresh, aggressively kawaii invitation to write notes; never repeat a previous sentence.
